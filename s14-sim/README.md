# S14 Drift Suspension Lab

Обучающий 3D-симулятор подвески Nissan Silvia S14 с передним кит-комплектом Wisefab V2:
как параметры подвески влияют на усилие и самовозврат руля в установившемся заносе.

```
npm install
npm run dev      # http://localhost:5173
npm test         # проверки физики (vitest)
npm run build
```

## Статус

| Этап | Содержание | Статус |

| 2 | Модель шины (Pacejka, пневматический трейл, давление) | **готов** |
| 3 | Установившийся занос и момент на руле | **готов** |
| 4 | Графики, A/B-пресеты, «Точка баланса», анализ чувствительности | **готов** |


## Исходные данные

Всё в [`src/config/vehicle.ts`](src/config/vehicle.ts). У каждой строки пометка
`[измерено]` (получено от пользователя) или `[предположение]`.

Подтверждено пользователем: Wisefab V2, ГУР, шины 245/40R18 по кругу, диф заварен,
рассматривается только установившийся занос, занос влево — положительный.

**Всё остальное — предположения**, в первую очередь координаты шарниров подвески, ход и
передаточное число рейки, длина рулевого рычага, настройки по умолчанию. Для реальных выводов
их нужно заменить измерениями с вашей машины.

## Система координат

Машина: X вперёд, Y влево, Z вверх, мм; начало — на земле под центром передней оси.
Углы: развал «−» верх внутрь; схождение «+» toe-in, на колесо; кастер «+» верх оси назад;
руль «+» влево.

## Этап 1: кинематика ([`src/physics/kinematics.ts`](src/physics/kinematics.ts))

Кулак — жёсткое тело с точками LBJ, UBJ (шаровые), OTR (шарнир тяги) и центром колеса.
Положение точки кулака в машине — цепочка преобразований:

1. поворот вокруг оси поворота (kingpin) на угол δ;
2. статические развал и кастер (подгоняются итерациями так, чтобы **измеренные** значения
   совпали с заданными: эти углы взаимосвязаны);
3. ход подвески: плоская (YZ) четырёхзвенка по нижнему и верхнему рычагам.

δ находится из замкнутой цепи «рейка → тяга → кулак»: `|OTR(δ) − ITR(рейка)| = L`.
Длина тяги `L` подбирается так, чтобы при центральной рейке схождение равнялось заданному
(при сдвиге рейки схождение «переставляется» заново — как после реальной регулировки).

Из итоговой геометрии измеряются: развал, кастер, KPI, курс колеса, механический трейл и
плечо обкатки (вдоль/поперёк курса колеса, по пятну контакта), бамп-стир и развал-гейн
(конечные разности ±10 мм хода).

**Аккерман.** Параметр «Аккерман, %» — угол рулевого рычага кулака в плане; он подбирается
так, чтобы *измеренный* Аккерман при внутреннем колесе 20° и штатной рейке равнялся заданному:
`Ак = (ctg δвнеш − ctg δвнутр) / (t / L)`. 0 % — параллельно, 100 % — идеальный Аккерман,
<0 — анти. Угол рычага дальше фиксирован, поэтому сдвиг рейки *меняет* измеренный Аккерман —
это эффект, который вы смотрите. Аккерман с рейкой не постоянен по углу: в панели показан
на 10/20/35°.

### Допущения и упрощения этапа 1

- Ход подвески считается в плоскости YZ; продольные смещения рычагов не учитываются.
- Левое и правое колесо зеркальны; ход подвески в UI — на оба колеса одинаковый
  (крен кузова добавится на этапе 3).
- Задняя подвеска пока схематична: статические развал/схождение, рычаги нарисованы
  для наглядности, кинематика хода не считается.
- Пятно контакта — нижняя точка цилиндра колеса (форма шины не учитывается); остаточная
  высота пятна над землёй (доли мм) — это «подъём» кузова при повороте кулака.
- Предел руля определяется ходом рейки, лимитом угла колеса (`maxWheelAngleDeg`) и
  «мёртвой точкой» тяги (тяга и рычаг в одну линию). **На текущих предположениях
  внутреннее колесо упирается примерно в 55–58°**, а не в 65–70° Wisefab: нужны реальные
  точки шарниров рейки и рулевого рычага.
- KPI в панели — измеренный, включая вклад развала (больше отрицательный развал → больше KPI).

## Этап 2: модель шины ([`src/physics/tire.ts`](src/physics/tire.ts), коэффициенты — [`src/config/tire.ts`](src/config/tire.ts))

Magic Formula (боковая сила) + пневматический трейл + влияние давления и развала.
Полный вывод формул и знаков — в комментарии в начале `tire.ts`. Кратко:

- **Пик сцепления** `μ` зависит от нагрузки (падает), давления (падает при росте) и развала (квадратично).
- **Жёсткость** `Cα` — формула Пачейки от нагрузки, растёт с давлением.
- **Боковая сила** — Magic Formula; **камбер-тяга** введена как сдвиг по углу увода `αe = α + (Cγ/Cα)·γ`,
  поэтому она естественно исчезает у пика.
- **Круг трения** для тяги: `Fy = Fy0·√(1 − (Fx/μFz)²)` (для заднего колеса в этапе 3).
- **Пятно контакта**: `l = Fz / ((p + pкаркаса)·ширина пятна)`. Давление ↑ ⇒ пятно короче ⇒ трейл меньше.
- **Пневматический трейл** `t0 = kT·l`, дальше падает с углом увода по `cos(Ct·atan(…))`, проходит через
  ноль около угла полного скольжения `αsl = atan(3μFz/Cα)` и уходит в минус. Именно это (знак момента
  шины в заносе) критично для того, куда «сваливается» руль.

Знаки: `α > 0` ⇒ сила влево; `γ` — наклон верха колеса в сторону +Y (для правого колеса `γ = −развал`);
`Mz = −t·Fy`.

С текущими коэффициентами для 245/40R18 при 3.2 кН и 2.0 бар: `Cα ≈ 640 Н/°`, пик Fy на ≈ 11°,
`t0 ≈ 17 мм`, ноль трейла ≈ 16°, минимум ≈ −5 мм.

### Допущения и упрощения этапа 2

- **Все коэффициенты шины — предположения**, не измерения. Калибровать нужно прежде всего
  `trailBu`, `trailCt` (где трейл меняет знак), `muPressSens`, `stiffPressSens` (как давление меняет сцепление).
- Модель стационарная: нет релаксации шины, нагрева и износа.
- Давление влияет только через длину пятна, жёсткость и пик сцепления; нет зависимости от температуры.
- Камбер-тяга линейна по `γ`; зависимость пика от развала — простая парабола, без оптимума.
- Круг трения — эллипс с `μx/μy = 1`; нет полной модели совместного скольжения.
- График шины показан для левого колеса при выбранной вертикальной нагрузке (по умолчанию статика оси).

## Этап 3: установившийся занос и момент на руле ([`src/physics/drift.ts`](src/physics/drift.ts))

Полный вывод формул — в комментарии в начале `drift.ts`. Кратко:

- Входы: угол заноса `s` (+ = влево), скорость `V`, газ. Неизвестные: рейка `x` (руль) и угловая скорость `r`.
- Скорость колеса `v_i = v + r × p_i`, угол увода `α_i = ψ_i − θ_i` (ψ — курс колеса: передних из
  кинематики этапа 1, задних — схождение).
- Нагрузки: статика + продольный перенос + поперечный перенос на наружные колёса.
  Крен (градиент `rollGradientDegPerG`) двигает колёса по ходу подвески и меняет развал
  относительно дороги: внутреннее колесо уходит в минус, наружное — в плюс.
- Тяга: `Fx = газ · maxTractionN`, делится между задними колёсами по нагрузке (заваренный диф);
  боковая сила ограничена кругом трения. Передние колёса свободно катятся.
- Уравнения: (1) сумма сил шин перпендикулярно скорости = `m·V·r`; (2) сумма моментов рыскания = 0.
  Решение: вложенные бисекции (r из (1), затем рейка из (2)); при нескольких равновесиях
  выбирается контрруль, ближайший к нулю.
- **Момент на руле**: для каждого переднего колеса `M_k = â·((c − p_lbj) × F) + â_z·Mz_шины`
  относительно оси поворота; `F` — полная сила на пятне (включая вертикальную `Fz`), `Mz_шины = −t_пневм·Fy`.
  Так в одном выражении учтены механический трейл, плечо обкатки, кастер, KPI,
  «подъём» кузова и пневматический трейл. По принципу виртуальной работы
  `F_рейки = Σ M_k,i · dδ_i/dx`, момент на руле `T = F_рейки · (мм хода на рад руля)`.
  Для ГУР в руке `T·(1 − assistFraction)`.
- Знак: `T > 0` — дорога тянет руль влево. В левом заносе контрруль отрицателен, поэтому
  `T > 0` — «тянет обратно», `T < 0` — «докручивает контрруль сама»; интерфейс пишет это словами.

### Допущения и упрощения этапа 3

- Установившийся режим: равновесие поперёк скорости и по рысканию; баланс **вдоль** скорости
  не накладывается, его невязка выводится как «ускорение вдоль скорости» (0 = скорость постоянна).
  Газ нужно подбирать, если хотите нулевое ускорение.
- Газ — это доля `maxTractionN` (конфиг), а не положение педали и не обороты; диф заварен, тяга делится по нагрузке.
- Тяга на заднем колесе ограничена долей `maxRearLongShare` (0.85) от `μ·Fz`: всё, что сверх, — пробуксовка, а не тяга.
  Поэтому при газе выше ≈ 70–80 % результат уже не меняется (шины на пределе по тяге).
- Крен: линейный градиент, без отдельного центра крена; геометрия подвески пересчитывается
  по ходу ±φ·колея/2, но наклон всей геометрии телом крена не учитывается (поправка порядка 1°).
  Задний развал меняется только от крена кузова (развал-гейн сзади не моделируется).
- Перенос веса: мгновенный, без динамики; доля переднего переноса `latTransferFrontPct` — предположение.
- Нет аэродинамики, сопротивления качению и трения в рулевом механизме и рейке; момент в руке с ГУР —
  грубая оценка (доля `assistFraction`), реальный ГУР нелинеен и зависит от торсиона и насоса.
- Передние шины катятся без продольного проскальзывания, поэтому сила строго поперёк курса колеса.
- Колёса считаются на пределе сцепления по модели шины этапа 2, значит весь результат
  настолько точен, насколько откалибрована шина (особенно знак пневматического трейла).

### Пример (настройки по умолчанию: 30°, 80 км/ч, 50 % газа)

Контрруль ≈ −247° руля (колёса ≈ −22…−24°), рыскание ≈ 0.38 рад/с, ≈ 0.74 g, задние шины на пределе
(≈ 31° увода), момент от дороги ≈ −25 Н·м (≈ −7.5 Н·м в руке): руль **докручивает контрруль сам**.

## Этап 4: графики, баланс руля, чувствительность ([`src/physics/analysis.ts`](src/physics/analysis.ts))

### Как пользоваться
1. Выставьте текущие настройки и сценарий заноса (угол, скорость, газ). Включён «Авто-контрруль» — руль подбирается из равновесия.
2. Нажмите **Сохранить A**, измените параметры, при необходимости **Сохранить B**. Выберите «Сравнивать графики с A/B» —
   на каждом графике появится оранжевая пунктирная линия пресета. Пресеты хранятся в браузере (localStorage).
   Пресет содержит только настройки подвески и шин; сравнение идёт **при текущем сценарии заноса**.
3. Смотрите блок «Точка баланса руля» (справа) и вкладку «Руль и занос» (внизу).
4. На вкладке «Чувствительность» нажмите «Анализ чувствительности» — получите рейтинг параметров.

### Что показывают графики
- **Момент на руле от угла руля** `T(δ | β)`: при фиксированном угле заноса. Точка «руль висит» — где `T = 0`;
  вертикальная пунктирная линия — равновесный угол руля `δ*`. Наклон кривой в нуле `dT/dδ < 0` — руль
  самоустанавливается в этой точке, `> 0` — убегает.
- **Момент на руле от угла заноса** `T_eq(β)` в равновесии (газ постоянен); `β*` — где `T_eq = 0`.
- **Углы увода** внутреннего и внешнего переднего колеса от угла руля.
- **Развал** внутреннего и внешнего переднего колеса относительно дороги (с учётом крена) от угла руля.

### Блок «Точка баланса руля»
- `β*` — угол заноса, при котором руль в установившемся заносе «висит». Ниже и выше `β*` показывается, куда руль
  сваливается: «докручивает контрруль сам» (`T < 0` в левом заносе) или «тянет обратно» (`T > 0`).
- `Δ = β* − рабочий угол` и наклон `dT_eq/dβ`: пологая (< 0.4 Н·м/°), средняя (< 1.2), крутая. Границы — предположение.
- Если `β*` в диапазоне 5–55° нет (момент не пересекает ноль), блок это пишет и показывает угол с минимальным `|T|`.
  Дополнительные метрики работают и без `β*`: угол руля `δ0`, где руль висит, против нужного `δ*`;
  чем меньше разница, тем меньше усилие, которое нужно прикладывать.
- Цель из задачи: `β*` совпадает с рабочим углом, наклон пологий, `δ0 ≈ δ*`.

### Чувствительность
Для каждого из 9 параметров (рейка, схождение/развал/давление спереди и сзади, кастер, Аккерман) считаются
значения при `+шаг` и `−шаг`; показан эффект от `+шага` по центральной разности (линейное приближение).
Столбцы: `Δβ*`, `ΔT` при рабочем угле заноса, `Δ(δ*−δ0)`. Рейтинг по `|Δβ*|`, а если `β*` нет — по `|ΔT|`.
Шаги: рейка 5 мм, схождение 0.2°, развал 0.5°, кастер 1°, Аккерман 20 %, давление 0.2–0.3 бар.

### Допущения и упрощения этапа 4
- `T_eq(β)` считается по сетке 5–55° с шагом 2.5° и линейной интерполяцией нуля; при некоторых углах равновесия
  может не быть (шины не хватает) — такие точки на графике пропущены.
- Кривая `T(δ | β)` берёт `r` из баланса сил (без баланса моментов рыскания) — это мгновенный «срез» при фиксированном заносе.
- Чувствительность считается при текущем сценарии и текущих настройках как локальная производная; для больших изменений
  параметров результат может отличаться (нелинейности, смена ветви равновесия).
- Пороги «пологая/крутая» и `Δ < 2°` для «цель достигнута» — предположения; подбираются по ощущениям на реальной машине.

## Результаты на настройках по умолчанию

С предположениями из `config` момент на руле во всём диапазоне заносов отрицательный: руль **докручивает контрруль сам**,
точки баланса `β*` нет. Это совпадает с одним из двух поведений, описанных на реальной машине. Рейтинг чувствительности
показывает, что сильнее всего приближают к «висит»: давление сзади (↑), кастер (↓), Аккерман (↓), давление спереди (↑).
Это следствие предположений модели, а не вывод для вашей машины: чтобы он стал таким, нужны реальные точки подвески и калибровка шины.

## Пример подбора: «руль не тянет» на 35° при полном газе

Задача: 35° заноса, 80 км/ч, газ 100 %, момент от дороги на руле ≈ 0 (на текущих предположениях
сейчас ≈ −11 Н·м: руль докручивает контрруль сам). Подбор — покоординатный поиск по 9 параметрам
с минимальным отходом от текущих значений, с проверкой на 25–40° заноса, 60–100 км/ч и газ 75–100 %.

| Параметр | Сейчас | Вариант A | Вариант B |
|---|---|---|---|
| Кастер | 7.0° | **4.0°** | **3.0°** |
| Развал (перед) | −4.0° | **−6.4°** | **−5.5°** |
| Схождение (перед, на колесо) | −0.10° | −0.20° | −0.20° |
| Давление (перед) | 2.0 бар | 2.1 бар | 2.1 бар |
| Давление (зад) | 2.8 бар | **3.5 бар** | **3.5 бар** |
| Остальное | | без изменений | без изменений |
| Момент на руле @35°/100 % | −11.1 Н·м | −1.6 Н·м (в руке ≈ −0.5) | −0.8 Н·м (в руке ≈ −0.3) |
| Руль «висит» при / нужен | −313° / −305° | −309° / −308° | −311° / −311° |

Вклад: основное даёт снижение кастера (меньше механический трейл) и повышение давления сзади (меньше сцепление
сзади → меньший момент на передней оси); развал и схождение донастраивают остаток.
Плата за вариант: меньше кастера — слабее самовозврат руля в прямой (смягчает ГУР); −6° развала — износ внутренней
кромки шины. Всё это справедливо только внутри модели с предположениями из `config`.

## Высота подвески, высота и положение центра тяжести

Добавлены параметры (левая панель):
- **Высота подвески (перед) и (зад)**, мм — клиренс. Задана **опорная высота** (`config.rideHeight`, сейчас 120 / 125 мм — предположение):
  при ней заданы слайдеры развала, кастера и схождения. Ниже опорной колёса оказываются в ходе сжатия на Δ мм:
  - перед: геометрия пересчитывается кинематикой по ходу подвески (развал-гейн, бамп-стир, трейл, плечо обкатки);
  - зад: линейные коэффициенты `config.rear.camberGainDegPer10mm` (−0.2°/10 мм) и `bumpSteerDegPer10mm` (+0.03°/10 мм) — предположения;
  - ЦТ смещается вместе с кузовом: `h_эфф = h_ЦТ + доля_перед·Δперед + доля_зад·Δзад`.
  После изменения высоты углы нужно «переразвалить» слайдерами — так же, как на машине.
- **Высота центра тяжести**, мм — значение при опорной высоте; влияет на продольный и поперечный перенос веса и крен.
- **Развесовка (на перед)**, % — положение ЦТ по длине; определяет статические нагрузки на оси и плечи моментов.

В 3D центр тяжести показан жёлтым шаром с кольцом; в блоке «Установившийся занос» выводится его эффективная высота.
Все три параметра участвуют в пресетах A/B и в анализе чувствительности (шаги 10 мм, 30 мм, 2 %).

Допущения: крен считается от эффективной высоты ЦТ и общего градиента `rollGradientDegPerG`, который от высоты ЦТ не пересчитывается;
задняя подвеска — по линейным коэффициентам, без полной кинематики; клиренс и высота ЦТ в конфиге — предположения, замените измеренными.
