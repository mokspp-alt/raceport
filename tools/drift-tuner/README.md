# Drift Tuner — симулятор настройки подвески для дрифта

Самодостаточная страница без сборки и зависимостей: откройте `index.html` в браузере.

- `physics.js` — модель (вид сверху, 4 колеса, динамика крена и тангажа, Pacejka-lite, круг трения, дифференциал, ручник). Подключается и в браузере, и через `require` в Node.
- `index.html` — интерфейс: ползунки подвески, пресеты, живая телеметрия, анализ настройки и подсчёт очков за дрифт.

Управление: `W`/`S` газ/тормоз, `A`/`D` руль, `Пробел` ручник, `Shift` рывок сцепления, `R` сброс. Геймпад: левый стик, RT/LT, A — ручник, RB — рывок.

Что на что влияет в модели:

| Параметр | Эффект |
|---|---|
| Пружины и стабилизаторы | жёсткость крена по осям → распределение переноса веса (LLTD) |
| Демпферы | скорость переноса веса в переходах (крен, тангаж) |
| Клиренс | высота центра тяжести и центров крена |
| Развал | пятно контакта: при крене внешнее колесо теряет отрицательный развал |
| Схождение | угол увода колёс: сзади «плюс» стабилизирует, спереди «минус» обостряет вход |
| Блокировка диффа | делит тягу между задними колёсами; открытый дифф буксует внутренним колесом |
| Баланс тормозов | при 100% на перед ручник/тормоз не сорвёт зад |
| Кастер | сила помощника контрруля |

Модель упрощённая и предназначена для понимания тенденций, а не для расчёта реальной машины.
